# SIDE C — Web App

SIDE C 是一个移动端优先的个人音乐与 MV 档案。此版本已从微信小程序结构转换为原生 Web App，可部署到 GitHub Pages。

> **让每张专辑，都有归处。**

## 本地预览

直接打开 `index.html` 通常可以预览核心功能。若要测试 PWA / Service Worker，请在项目目录启动静态服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `side-c`。
2. 解压项目，将本目录内的所有文件上传到仓库根目录（确保 `index.html` 位于根目录）。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 Save。
6. 等待 GitHub Pages 部署完成，网址通常为 `https://你的用户名.github.io/side-c/`。

如果仓库名是 `你的用户名.github.io`，网址则是 `https://你的用户名.github.io/`。

## 当前功能

### 开屏与外观

- **开屏界面**：每次打开先显示 SIDE C 开屏页 —— 标语「让每张专辑，都有归处。」，底部有进度条，约 2.8 秒后自动进入，也可以点「进入档案」立即跳过。
- **Apple 质感**：全局毛玻璃（高斯模糊 + 饱和度提升）、发丝级描边、Spring 缓动、系统字体栈、动态环境光背景；深色 / 浅色主题随时切换。

### 音乐与 MV 档案

- **网格 / 列表双视图**：音乐档案和 MV 页都可以在「网格」与「列表」之间切换，列表模式下每一条都是带圆角边框的独立卡片。
- **按时间搜索**：搜索框支持专辑 / 艺人 / 歌曲 / MV 标题，也可以直接输入 `2026`、`2026-03` 这样的时间关键词；另有「年份」「月份」两个下拉筛选，可叠加使用。
- 专辑搜索一键导入封面、简介、曲目（Apple Music / 可选网易云 / 维基百科），也可手动添加；日期、评分、标签、链接、个人笔记。
- MV 档案：添加、搜索、外链，详情页内嵌 B站 播放器（16:9）。

### 专辑记录

- **编辑记录**：专辑和 MV 的详情页都有「编辑记录」按钮，可以重新修改封面、日期、评分、简介、标签、曲目和笔记。保存时，曲目里已经点亮的 ♡、写过的备注、挂上的 MV 都会原样保留。
- **曲目挂 MV**：专辑曲目列表里每首歌旁边有一个圆形图标。点一下可以从「你已经添加过的 MV」里挑一条挂上，挂好之后圆形图标里直接显示这张 MV 的封面；再点封面可以直接跳到 MV 页面。图标右上角的小 × 可以随时解除挂载。
- 逐首喜欢标记、单曲个人笔记。

### 歌单

- 红心歌曲自动汇总为「全部红心」和按歌手划分的歌单，可复制 / 导出 TXT、CSV 用于迁移到网易云或 Spotify。
- **自建歌单**：点「＋ 新建歌单」可以自己创建歌单，歌单里的歌曲只能从红心里挑选；歌单名字随时可以改，也可以把歌从歌单里移出或整张删除。

### 年度回顾

- 「我的空间 → 年度回顾」点进去可以看到当年专属页面：专辑 / MV / 红心 / 被记录天数四项统计、一整年的**记录小格子**（GitHub 式活跃度热力图，颜色越深说明那天记录的越多）、今年听的专辑和看的 MV 清单。
- 支持导出 **TXT / JSON**，也可以一键复制摘要。

### 其他

- 时间线、艺人统计、标签汇总。
- JSON 备份导出与导入。
- 首页底部有「**支持作者**」（打开作者作品与小红书二维码）和「**提出建议**」（显示联系邮箱 ouch61@126.com）两个入口。
- 响应式布局、可安装 PWA 基础支持、静态资源离线缓存。

## 数据与隐私说明

当前数据使用浏览器 `localStorage` 保存在当前设备和浏览器中，不会自动上传到 GitHub 或服务器。换设备、换浏览器或清除站点数据不会自动同步；请在「我的空间」定期导出 JSON 备份。任何人访问你的 GitHub Pages 网站都能打开应用，但每个人的数据默认只保存在自己的浏览器本地。此版本没有账号系统、云端同步或服务端权限控制。

本版本新增的数据键：`sidec_web_playlists`（自建歌单）、`sidec_web_views`（网格 / 列表视图偏好）。「支持作者」弹窗里的图文是固定的，图片位于 `assets/sponsor-card.jpg`。

## 自动抓取说明

- 专辑搜索：默认使用 Apple Music (iTunes Search API，中国区 + 美国区)，无需 Key；简介优先取网易云（需配置），否则取维基百科。
- MV：只支持 B站。输入歌名搜索，或直接粘贴你的 B站 视频链接（含「【标题】https://…」这种分享文本）自动解析标题、UP主、封面；MV 详情页会内嵌 B站 播放器（16:9）。
- B站 不允许网页直接访问，需要一个免费的 Cloudflare Worker 中转：

### 部署中转接口（约 5 分钟）

1. 注册并登录 Cloudflare → Workers & Pages → Create → Create Worker → Deploy。
2. 点 Edit code，删掉默认代码，粘贴本项目 `worker/proxy-worker.js` 的全部内容，Deploy。
3. 复制得到的网址（形如 `https://xxx.你的名字.workers.dev`）。
4. （可选）在 Worker 的 Settings → Variables 添加 `ALLOWED_ORIGIN` = `https://你的用户名.github.io`，只允许你的网站使用。
5. 打开网站 → 浏览器控制台（F12）执行下面这行，把接口地址填进去：

```js
localStorage.setItem('sidec_web_settings', JSON.stringify({ proxy: 'https://xxx.你的名字.workers.dev' }));
```

说明：workers.dev 域名在部分网络环境下访问不稳定；如遇到，可给 Worker 绑定自己的域名。未填接口地址时，粘贴 B站 链接仍会识别并填入链接、内嵌播放，但无法自动获取标题和封面。

- 网易云：可选，填入自己部署的 NeteaseCloudMusicApi（需 https），同样通过上面的 `localStorage` 方式配置：

```js
localStorage.setItem('sidec_web_settings', JSON.stringify({ neteaseProxy: 'https://你的接口.vercel.app' }));
```

- 外部接口请求不会被 Service Worker 缓存。
